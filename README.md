# Самокат YGW 5.0 — 3D-схема

Интерактивная 3D-модель электросамоката YGW 5.0 с разбором по деталям.

- **Режимы:** собран, рентген, разрез, разнесённый вид, все детали.
- **Карточка детали:** артикул, название (англ./кит.), количество на самокат, цена 2025, MOQ, срок поставки и фото из каталога запчастей.
- **Кнопка «Снять крышку АКБ»**: снять крышку → снять аккумулятор → собрать обратно.

Открывается в браузере, установка не нужна: `index.html` в корне, фото деталей в папке `thumbs/`.
Модель упрощённая. Габариты как у реального самоката: длина по колёсам 1,16 м, высота до держателя телефона 1,22 м. Пропорции выверены по замерам рулеткой и 3D-скану, задний обтекатель построен по скану детали; 115 деталей, 90 артикулов каталога из 121. Мелкие детали расставлены по рисункам каталога.
